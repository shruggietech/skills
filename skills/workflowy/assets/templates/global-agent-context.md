## Workflowy

Use the `workflowy` skill for substantive work with the operator in their
private agent workspace. Route named projects under **PROJECTS**. Use
**PERSONAL > notes** for generic non-project work. Load the relevant
**STANDARDS** before performing governed work. Use **REFERENCE** for shared
entities, definitions, and remote sources. Follow the skill's layout and
record rules. The operator decides what is published.

Write records as normal bullets. Never use comments or comment drafts for
record storage. Put dated records directly under `notes`, oldest first,
with only the most precise supported ISO 8601 date or timestamp as title.
Use standalone `Title`, `Tags`, and `Details` labels and nest each value
under its field. Require the Workflowy bullet format for fields and values.
Only the contents of `Details` may use other formats. Link related records and exact evidence with one link per
bullet. The operator owns timeline construction. Record dates without
creating timeline metadata, views, searches, or exports.

Desktop MCP requires a running, signed-in Workflowy app with Local MCP
enabled and a connected client. A cloud or other nonlocal agent can use a
separately configured, operator-authorized connector. Confirm the intended
destination and read back edits. If no connector is available, continue
under the available instructions and provide an appropriately private,
ready-to-paste nested outline with its exact destination, marked unsynced.
